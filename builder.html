How this works
  1. Columns are read from MSSQL INFORMATION_SCHEMA — the AX source, not ClickHouse.
  2. dimension = the grain. Dimensions become the ORDER BY key.
  3. measure / fact = the raw value, carried across unchanged.
  4. aggregate = a rolled-up column COLUMN_agg. Add the same column again for a second aggregation. Any aggregate makes it an AggregatingMergeTree.
  5. The DDL below is built on the server from the column types — the page never sends SQL.
  6. Create runs it. The table is empty until you press Load.
  7. Load pulls raw rows from MSSQL and lets ClickHouse aggregate them. It truncates first, so running it twice does not double your numbers.
  8. Read an aggregate table with GROUP BY on the key and the *Merge() functions — parts merge in the background, so raw SELECT * can show several rows per key.
