# PUC Dashboards in Power BI

`PUC Dashboards.pbip` is a complete Power BI project: the data model (8 tables,
10 relationships, 52 KPI measures from the KPI catalogue) and 10 report pages.
It reads the ClickHouse `ub` database directly over HTTP, so no ODBC driver is needed.

## Open it (Windows PC with Power BI Desktop)

1. Get this folder on the PC: download the repository as a ZIP from GitHub
   (branch `claude/jolly-pasteur-q1n386`) and unzip it, or `git clone` it.
2. In Power BI Desktop, go to **File → Options and settings → Options → Preview features**. If any of
   these are listed, tick them and restart Power BI:
   - *Power BI Project (.pbip) save option*
   - *Store semantic model using TMDL format*
   - *Store reports using enhanced metadata format (PBIR)*
3. Double-click **`powerbi/PUC Dashboards.pbip`**.
4. Click **Refresh**. When asked how to connect to `http://192.168.11.71:8123/`, choose
   **Anonymous → Connect**. Loading takes about a minute: 581k billing lines plus the smaller tables.

A different ClickHouse server, user or password: go to **Home → Transform data → Edit parameters**,
then `ClickHouseUrl`, `ClickHouseUser` or `ClickHousePassword`.

ClickHouse must accept network connections (`listen_host` 0.0.0.0), and port 8123 must be reachable
from the PC. Check by opening `http://192.168.11.71:8123/play` in the PC's browser.

## The pages

| # | Page | Filtered to |
|---|---|---|
| 1 | Executive Overview | all utilities |
| 2 | Electricity | Electricity |
| 3 | Water | Water |
| 4 | Sewerage | WasteWater |
| 5 | Tariff and Sector | pick one utility |
| 6 | Customers and Connections | pick one utility |
| 7 | Billing Controls | all, or pick |
| 8 | Solar PV | Electricity |
| 9 | Water Network | Water |
| 10 | Consumption Analytics | pick one utility |

Consumption measures (kWh, m³) are blank when more than one unit is in view: kWh and m³ can't be
added together. Pick a utility to see them. Growth % compares the latest selected period with the
period before it in the data.

## Changing it

The project is generated by `build_pbip.py`, which holds the tables, measures and pages. Edit it and
run `python3 powerbi/build_pbip.py`. Pages you rearrange inside Power BI Desktop and save are also
fine, but the next generate overwrites them.

New data: load it into ClickHouse (`ub_load.py`), then press **Refresh** in Power BI.
